# Cockpit v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split the pad into workspaces (top 6 keys) + tmux windows of the
focused footguard session (bottom 6 keys), with an inverted identity header and
window legend on the OLED, bell-driven blinking on both halves, and
workspace-identity colors mirrored into the tmux status bar.

**Architecture:** The existing keymakerd daemon gains a tmux CLI wrapper and a
ContextWatcher asyncio task that emits a new state-shaped `ctx` message; the
pad stays semantics-free (still sends `key(n, tap|hold)`; the daemon interprets
the split). The bell pipeline is pure host config — one foot.ini stanza
completes an already-configured BEL chain. Status-bar colors derive from the
same name-keyed hash as workspace names, so no IPC is needed anywhere.

**Tech Stack:** Python 3.13 asyncio (daemon), CircuitPython 10.2.1 (firmware),
tmux CLI, Hyprland IPC, bash + tmux formats (status bar), pytest (dev venv).

**Spec:** `docs/specs/2026-08-15-cockpit-v2-design.md` — binding authority for
every task. Read it before ruling on any ambiguity.

## Global Constraints

- **No new runtime dependencies.** Daemon runs on system python + python-pyserial (pacman). Dev-only tools live in `.venv`. No AUR, ever.
- **The daily-driver tmux server is sacred.** Its configuration is never modified. Tests use isolated servers only (`tmux -L <unique-socket> -f <own-conf>`); the live server is touched only by user-option stamping (`@wsid_*`) and `select-window` on an explicit key tap.
- **Protocol changes are additive only.** v1 firmware against v2 daemon (and reverse) must degrade to v1 behavior, never crash.
- **Firmware guards use `except Exception`, never `BaseException`** — Ctrl-C REPL access must survive.
- **Never type a literal Nerd Font/PUA glyph in any tool call** (statusbar.conf contains U+E0B0 chevrons and other PUA glyphs). Copy existing glyph text programmatically (slicing lines already read from disk) or generate via `chr(0xE0B0)`; verify edits with `od -c` where glyphs are involved.
- **tmux windows are 1-indexed** (`base-index 1`, `renumber-windows on` — verified live on nexus, and now pinned fleet-wide via chezmoi `~/.tmux.conf`). Slot N ↔ window index N with no gaps.
- **Key commands:** tests `.venv/bin/pytest -q` (repo root); firmware deploy `./system/deploy-firmware.sh`; daemon `systemctl --user restart keymaker.service`; firmware console probe `timeout 4 cat /dev/keymaker-repl || true` (expect no traceback).
- **Execute on a `cockpit-v2` branch in `~/src/keymaker` itself, not a detached worktree** — the systemd unit's PYTHONPATH and the deploy script point at this checkout, and live smokes need the running daemon to be the branch code.
- **Repo routing:** keymaker code/docs → keymaker repo (`feat:`/`fix:`/`docs:`). `scripts/wsid-tmux-colors` and setup.md → oracle repo (`feat:`/`docs(setup):`). `~/.config/tmux/statusbar.conf` → `chezmoi re-add` + a dotfiles commit containing ONLY that file (two unrelated modified files await Chris there — never commit them). `~/.claude/settings.json` is chezmoi-DIVERGENT: never `chezmoi re-add` it; report any edit for the pending ledger. `~/.config/foot/foot.ini` is deliberately chezmoi-untracked: local edit only.

```python
"""tmux CLI wrapper: window lists and switching. Subprocess-per-call; never raises."""
import asyncio

FORMAT = "#{window_index}\t#{window_active}\t#{window_bell_flag}\t#{window_name}"


async def _run(*args):
    proc = await asyncio.create_subprocess_exec(
        "tmux", *args, stdout=asyncio.subprocess.PIPE,
        stderr=asyncio.subprocess.DEVNULL)
    out, _ = await proc.communicate()
    return proc.returncode, out.decode(errors="replace")


def parse_windows(out):
    items = []
    for line in out.splitlines():
        parts = line.split("\t", 3)
        if len(parts) != 4:
            continue
        idx, active, bell, name = parts
        try:
            i = int(idx)
        except ValueError:
            continue
        items.append({"i": i, "name": name,
                      "active": active == "1", "bell": bell == "1"})
    return items


async def list_windows(session, run=_run):
    """Windows of a session as [{i, name, active, bell}], or None on failure."""
    try:
        rc, out = await run("list-windows", "-t", "=" + session, "-F", FORMAT)
    except OSError:
        return None
    if rc != 0:
        return None
    return parse_windows(out)


async def select_window(session, i, run=_run):
    """Select window i of session (exact-name match). True on success."""
    try:
        rc, _ = await run("select-window", "-t", "=%s:%d" % (session, i))
    except OSError:
        return False
    return rc == 0
```

The `=` prefix forces exact session-name matching — without it, tmux
prefix-matches and `mac` would resolve to `macropad`.

```python
def ctx_key_color(item, pal, phase=0.0):
    """Bottom-half key color for one ctx slot item, or None for an empty slot."""
    if item is None:
```

```python
_EMPTY_CELL = ".      "


def ctx_legend(items, rows=((1, 2, 3), (4, 5, 6))):
    """Two 21-char OLED lines labelling the bottom key rows.

    Cell = index digit, marker (! bell > * active > space), name cut to 4,
    trailing space — the marker hugs its index so cells never collide.
    """
    by_i = {}
    for it in items:
        by_i[it["i"]] = it
    lines = []
    for row in rows:
        cells = []
        for i in row:
            it = by_i.get(i)
            if it is None:
                cells.append(_EMPTY_CELL)
            else:
                m = "!" if it.get("bell") else ("*" if it.get("active") else " ")
                name = it.get("name", "")[:4]
                cells.append(str(i) + m + name + " " * (5 - len(name)))
        lines.append("".join(cells))
    return lines
```

```bash
#!/usr/bin/env bash
# wsid-tmux-colors — stamp workspace-identity colors into tmux user options.
#
#   @wsid_color   (per session) : wsid hash of the session name. footguard keeps
#                                 session == workspace label, so the status bar,
#                                 the workspace pill, and the macropad key agree
#                                 by pure derivation (color = hash(name)) — no IPC.
#   @wsid_win1..6 (global)      : fixed per-index bins for window-status entries,
#                                 hue-locked to the macropad's bottom-key colors.
#
# Invoked from statusbar.conf behind an if-shell existence guard; on machines
# without the wsid lib (thinkpad, rika) the guard fails and the bar keeps its
# ANSI colors. Theme-aware via the wsid lib's light.mode check. Inside tmux
# run-shell, $TMUX routes the bare `tmux` calls to the invoking server;
# WSID_TMUX_CMD overrides for tests ("tmux -L somesocket").
set -euo pipefail

WSID_LIB="$HOME/oracle/scripts/workspace-identity-lib"
[[ -r "$WSID_LIB" ]] || exit 0
# shellcheck source=/dev/null
source "$WSID_LIB"

read -ra TMUX_CMD <<< "${WSID_TMUX_CMD:-tmux}"
command -v "${TMUX_CMD[0]}" >/dev/null || exit 0

if [[ -f "${WSID_THEME_DIR:-$HOME/.config/omarchy/current/theme}/light.mode" ]]; then
  pal=("${WSID_PALETTE_LIGHT[@]}")
else
  pal=("${WSID_PALETTE_DARK[@]}")
fi

for i in 1 2 3 4 5 6; do
  "${TMUX_CMD[@]}" set -g "@wsid_win${i}" "#${pal[$(( (i - 1) % ${#pal[@]} ))]}" \
    2>/dev/null || exit 0
done

while IFS= read -r s; do
  [[ -n "$s" ]] || continue
  "${TMUX_CMD[@]}" set -t "=$s" @wsid_color "$(wsid_color 0 "$s")" 2>/dev/null || true
done < <("${TMUX_CMD[@]}" list-sessions -F '#{session_name}' 2>/dev/null || true)
```
